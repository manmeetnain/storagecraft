<CardGrid>
  <Card title="Learn" icon="open-book">Build a precise mental model with plain-language explanations and a glossary.</Card>

## Your first 30 minutes

<Steps>
1. Learn how block, file, object, LUN, and filesystem differ in [Storage foundations](/storagecraft/learning/storage-basics/).
2. Compare capacity and failure tolerance in the [Universal RAID Planner](/storagecraft/simulators/raid-planner/).
3. Trace host → fabric → target → LUN in [SAN fundamentals](/storagecraft/learning/san-fundamentals/).
4. Inspect a simulated fabric in Learn mode using the [Storage Network Academy](/storagecraft/simulators/network-academy/).
</Steps>

> StorageCraft is educational engineering software. Simulators intentionally model selected behavior. Validate identities, commands, workload assumptions, platform releases, and recovery procedures before production use.
