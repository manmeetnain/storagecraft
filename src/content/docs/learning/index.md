## The complete path

This program turns StorageCraft's concepts, calculators, failure labs, and terminal academy into one ordered journey. Complete the modules in sequence if you are new; experienced engineers can use the outcomes to select a gap directly.

| Module | Level | Time | You will be able to |
|---|---:|---:|---|
| [1. Storage building blocks](./storage-basics/) | Foundation | 35 min | map block, file, object, LUN, volume and filesystem layers |
| [2. Performance fundamentals](./performance/) | Foundation | 40 min | reason about IOPS, bandwidth, latency and queues |
| [3. Data protection](./data-protection/) | Foundation | 45 min | distinguish availability, durability, snapshots, replication and backup |
| [4. SAN architecture](./san-fundamentals/) | Foundation | 45 min | trace a redundant host-to-LUN data path |
| [5. Fibre Channel fabric](./fc-fabric/) | Practitioner | 55 min | inspect logins, services, ports, ISLs and fabric health |
| [6. Zoning and safe change](./zoning/) | Practitioner | 55 min | create, activate, verify, roll back and remove zoning |
| [7. iSCSI and multipathing](./iscsi-multipath/) | Practitioner | 50 min | diagnose network, discovery, session, authentication and path policy |
| [8. Operations and incidents](./operations/) | Practitioner | 60 min | gather evidence and isolate failures without destructive guessing |
| [9. Practical assessment](./assessment/) | Assessment | 75 min | demonstrate the full operational workflow |

## Four learning modes

- **Learn:** read the mental model and inspect a safe example.
- **Practice:** follow a guided task with hints and visible success criteria.
- **Challenge:** solve an objective without command-by-command instructions.
- **Assess:** complete hidden checks and export evidence from the Network Academy.

## Completion standard

A learner should not claim completion from reading alone. Finish the linked practice, explain the check questions in your own words, and capture the evidence requested by the assessment module.

## Before you begin

Use a modern browser. The simulations are educational and never connect to real infrastructure. Vendor-inspired commands model public concepts and an explicit compatibility subset; always verify syntax and behavior against the exact production version.

Use the [standards and vendor source shelf](/storagecraft/reference/source-shelf/) to validate terminology, protocols, and release-specific commands.
