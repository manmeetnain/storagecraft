## What is inside

- A decision map for choosing ChatGPT, Codex, a skill, or a connector
- Current Codex surfaces, repository instruction layers, permissions, and delivery patterns
- A grouped skill shelf with examples such as `$visualize:visualize`, document creation, browser QA, Figma, spreadsheets, and plugin management
- A shortcut decoder for `$`, `@`, `/`, keyboard commands, and `codex://` deep links
- A plain-language map of skills, plugins, connectors, and MCP servers
- Original copyable prompt contracts and links to official OpenAI references

Availability varies by plan, workspace, product surface, authentication, region, and administrator policy. Use the linked official documentation as the source of truth for current behavior.

## What makes this collection different

- StorageCraft prompt templates are original and reusable.
- Official OpenAI documentation is clearly separated from community material.
- Community repositories include license and provenance labels.
- The hub teaches prompt structure and evaluation instead of presenting prompts as magic commands.
- Search, category filters, and copy controls make the collection usable without an account or API key.

## Prompt quality contract

A dependable prompt defines the outcome, relevant context, constraints, observable success criteria, evidence expectations, output shape, and what to do when blocked. Agentic prompts additionally define authority boundaries, approval points, stopping conditions, and verification.

Feature availability changes across plans, workspaces, regions, and product releases. Follow the official links in the hub for current availability and never include secrets or sensitive personal data in reusable prompts.
