One learning system, four ways to build skill

Section titled “One learning system, four ways to build skill”

Learn

Build a precise mental model with plain-language explanations and a glossary.

Practice

Operate visible state in calculators, failure labs, and vendor-style terminals.

Challenge

Diagnose incidents and make safe changes without step-by-step prompts.

Assess

Prove command selection, troubleshooting, rollback, and communication.

Start at your level

Section titled “Start at your level”
Beginner · Zero-to-SAN Engineer Nine ordered modules: storage, performance, protection, SAN, FC, zoning, iSCSI, operations, and assessment.
Operator · Runbooks Use repeatable procedures for daily checks, provisioning, incident triage, and safe rollback.
Practitioner · Storage Network Academy Operate Brocade-style FC, Cisco MDS-style FC, iSCSI, dual fabrics, incidents, and certification scenarios.
Architect · Storage × AI Labs Model GPU memory, KV cache, RAG footprints, NVMe queues, and end-to-end AI bottlenecks.
Developer · Python and CLI Reuse transparent models from Python, automation, notebooks, or the colored JavaScript CLI.
Track progress · Evidence and milestones Record completed modules locally, earn learning milestones, and export portable JSON evidence.

Your first 30 minutes

Section titled “Your first 30 minutes”
  1. Learn how block, file, object, LUN, and filesystem differ in Storage foundations.
  2. Compare capacity and failure tolerance in the Universal RAID Planner.
  3. Trace host → fabric → target → LUN in SAN fundamentals.
  4. Inspect a simulated fabric in Learn mode using the Storage Network Academy.
